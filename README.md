# Минамото — сайт в стиле Японии эпохи Эдо

## Файлы
- `index.html` — сайт, стили и переключение разделов.
- `assets/banner.png` — баннер.
- `assets/logo.png` — логотип.

## Публикация через GitHub Pages
1. Создайте новый репозиторий на GitHub.
2. Загрузите `index.html` и папку `assets` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт.

Тексты разделов находятся в объекте `sections` внизу файла `index.html`. Их можно заменить на свои.
